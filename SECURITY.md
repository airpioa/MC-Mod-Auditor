# Security Policy

## Supported Versions

Only the latest version of **MC-Mod-Auditor** available on the `main` branch is supported with security updates and bug fixes.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of MC-Mod-Auditor seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

### How to Report
* **Private Disclosure:** Please submit security reports privately through GitHub's [Security Advisory Portal](https://github.com/airpioa/MC-Mod-Auditor/security/advisories/new).
* **Information to Include:**
  * Steps to reproduce the issue.
  * The potential impact of the vulnerability.
  * Any relevant log outputs or code samples.

### Response Timeline
* **Acknowledgement:** You will receive an initial response likely within **48 hours**.
* **Fix & Patch:** If confirmed, a fix will be developed and released in a patch update as soon as possible.

Thank you for helping keep MC-Mod-Auditor safe!
